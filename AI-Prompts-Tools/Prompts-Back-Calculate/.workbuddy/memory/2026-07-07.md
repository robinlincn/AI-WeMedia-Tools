- 多线程下载正确姿势：用 bash 后台作业 `( curl -r START-END -o part_i URL ) &` + `wait` 做 8 并发，实测 ~277KB/s，104MB 约 7 分钟下完。
- 坑：`xargs -P` 内联注入大变量（SIZE/PART）在 Git Bash 下报 `environment is too large for exec`，分块文件全空。改用纯 bash 循环 `&`+`wait`。

- yt-dlp 装完后若不在 PATH，需把 Python 的 Scripts 目录加入 PATH 才能全局调用。
