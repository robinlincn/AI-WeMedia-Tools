## 经验（重要、可复用）
- **抖音 CDN（*.douyinvod.com）不限 IP**，但抖音 share 页（iesdouyin/share/video）对云 IP 返 200 OK SIZE=0
- **破局标准路径**：让用户从本机 Chrome DevTools Network 抓 mp4 源 URL（5-10 秒动作）→ curl/PowerShell 直连 CDN 拉

- **iesdouyin / m.iesdouyin / www.douyin 三个域对腾讯云 IP 段 TCP 拒绝或 200 SIZE=0**
- **长链 `www.douyin.com/video/{id}` 在 douyin-downloader-skill 里能跑通**（颠覆之前判断）：脚本 `get_real_url` 看到含 `douyin.com/video/` 直接 return 不再走 301，iesdouyin 拿页成功拿 `_ROUTER_DATA`，下 `aweme/v1/play/` 拿低码率 4:3 分享版（10MB / 53kbps）；而短链 `v.douyin.com/{code}/` 走 301 到 iesdouyin 时云 IP 返 0 bytes 失败
